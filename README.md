# CJ — инсоляция в SketchUp

## Установка на рабочий компьютер

Готовое расширение: `dist/cj-insolation-0.1.0.rbz`.
Поставить через Extensions → Extension Manager → Install Extension.
Инструкция для коллег: [INSTALL.md](INSTALL.md). Нужен SketchUp 2022+;
Codex, MCP, Python и доступ к интернету для расчёта не требуются.

## CSV и номера точек

Главные столбцы CSV: «Инсоляция проходит», основание и два признака выполнения
условий. Приняты правила пользователя: >=90 минут непрерывно ИЛИ >=120 минут
прерывисто при наличии сегмента >=60 минут. Шаг вектора — 1 минута;
сумма, максимум и список интервалов также выводятся в минутах.
Номера минут на поверхности начинаются с 1; после перерыва продолжают
независимый накопленный счёт для солнца и тени.

Перед выбором точек открывается выбор папки CSV. Последняя папка запоминается,
но её можно менять при каждом запуске. Отмена выбора отменяет запуск.
Каждый новый расчёт сохраняет отдельный CSV в выбранной папке.
Имя содержит дату и уникальный ID расчёта. Кодировка UTF-8 с BOM,
разделитель `;`, десятичная запятая — для открытия в русской версии Excel.
На каждую точку одна строка: номер, мировые координаты в мм, всего/свободных/
перекрытых отсчётов, последовательность длин солнечных интервалов,
максимальный интервал, режим отображения и ID/дата расчёта.

Номер точки сохраняется в атрибутах, названии подгруппы и итоговой подписи.
Нумерация продолжается при следующих расчётах в этой модели. CSV использует
тот же номер. Привязка к номеру помещения/окна и повторный расчёт сохранённой
точки пока не реализованы. Одно окно пока означает одну выбранную точку.

Новые поверхности имеют 50% прозрачности с обеих сторон, чёрные точки и
текст остаются непрозрачными. При расчёте включается отображение прозрачных
материалов. Старые поверхности нужно пересчитать для применения новых материалов.

## Инструменты разработки

Главная страница: [tooling/README.md](tooling/README.md). Создан локальный мост,
который принимает команды через файлы и выполняет их внутри SketchUp без
управления экраном. Здесь же перечислены текущие инструменты и план MCP.

## Исходники

- `src/cj.rb` — рабочая версия: пакетный выбор и исключение результатов из расчёта.
- `reference/downloaded_cj_v1.rb` — исходный файл из Downloads до доработки.
- `reference/installed_cj_2022.rb` — копия ранее установленной версии SketchUp 2022.
- `reference/installed_cj_loader_2022.rb` — копия её загрузчика.
- `dev/session.rb` — загрузка рабочей копии и базовые проверки в настоящем SketchUp.

Установленная версия отличается от переданного файла. Файлы в Plugins не изменяются.
Загрузка рабочей копии переопределяет модуль CJ::RayTubesUp только в текущем процессе.
После перезапуска SketchUp снова загрузится установленная версия.

## Цикл разработки

Открыть Extensions → Developer → Ruby Console и выполнить:

```ruby
Kernel.load('C:/Users/Golyatin.av/Documents/ChatGPT/Skethcup инсоляция/dev/session.rb')
```

После изменения исходников:

```ruby
CJDevelopment.reload
CJDevelopment.check
```

Повторная загрузка методов работает без перезапуска SketchUp. Загрузчик сбрасывает
кэш `@ray_vectors`; изменения меню и панели могут потребовать
перезапуска из-за существующей защиты от повторного создания интерфейса.

Явный `Kernel.load` нужен из-за установленного RhinoInsideSU: он определяет
собственный метод `load` и перехватывает обычный вызов из Ruby Console.

Результат проверки записывается в `reports/session_check.json`. Проверяются загрузка,
нормализация векторов, подсчёт непрерывных серий и доступ к raytest. Эти проверки
не подтверждают корректность нормативной методики или отсутствие взаимного
влияния конусов. Для этого нужны отдельные геометрические сценарии.

Codex может управлять SketchUp через Computer Use, вводить команды в Ruby Console,
читать отчёты и визуально проверять результат. Окно должно быть доступно на
разблокированном рабочем столе; во время автоматических действий лучше не
перехватывать мышь и клавиатуру.

## Следующие изменения

1. Сохранение расчётных точек и повторный выбор маркеров.
2. Привязка векторов к времени, дате, северу и источнику данных.
3. Режим без объёмных конусов для больших моделей.

## Выбор нескольких точек

В текущем сеансе рабочая версия загружена через MCP. Запустите обычную команду
CJ в SketchUp. Перед выбором точек появляется выбор отображения: «Конусы»,
«Линии», «Поверхность» или «Итоги» (без лучей). Режим выбирается кнопкой
в отдельном окне с пояснениями.
Клики добавляют точки с номерами Т1, Т2 и т. д.; Enter запускает
общий расчёт. Backspace убирает последнюю точку, Esc отменяет весь выбор.
Повторный клик в пределах 0,1 мм от уже выбранной точки пропускается.
Точки при выборе рисуются во View, не создавая препятствий в модели.

Результат — одна группа в корне модели с отдельной группой для каждой точки;
весь запуск отменяется одной командой Undo. Сначала рассчитываются все точки,
затем строятся конусы. Группы результатов помечаются атрибутом CJ_Insolation.
Перед расчётом они скрываются и затем возвращаются к прежней видимости.
Распознаются и старые результаты с именем Insolation_YYYYMMDD_HHMMSS на теге RAYS.
Произвольная архитектурная геометрия на теге RAYS не исключается.

Файлы Plugins не обновлялись. После перезапуска SketchUp рабочую версию можно
снова загрузить через MCP `sketchup_reload_plugin`. Интерактивную удобность
выбора и расположение подписей ещё нужно проверить на вашей рабочей модели.
