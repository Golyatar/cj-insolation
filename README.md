# CJ — инсоляция в SketchUp

Расчёт нескольких точек по фиксированному набору из 510 направлений. Одна выборка соответствует одной минуте. Пользовательская методика: 90 минут непрерывно либо 120 минут прерывисто с сегментом не менее 60 минут; пороги проверяются тестами.

## Использование

Установить `dist/cj-insolation-0.2.0.rbz` через Extension Manager в SketchUp 2022+. Codex, MCP и Python для расчёта не нужны. [Инструкция](INSTALL.md).

На панели **«CJ Инсоляция»** кнопка **«Настройки CJ»** объединяет размеры окна, вид результата (**Линии**, **Поверхность**, **Итоги**), радиус маркера и автопересчёт после перемещения. Настройки сохраняются между запусками. Размеры применяются при следующей вставке окна, оформление — при следующем расчёте. Команда **«Инсоляция — выбрать точки»** сразу включает выбор. Enter сохраняет точки и запускает расчёт, Backspace убирает последнюю точку, Esc отменяет выбор. Лучи зелёные на свободных направлениях и красные на затенённых. Поверхности полупрозрачные; подписи минут ведут отдельный накопленный счёт солнца и тени с единицы.

Расчётные точки обычного выбора сохраняются отдельными группами в SKP, независимо от результатов. Их оранжевые маркеры можно выделять рамкой или с Shift, затем перемещать обычным **Move (M)**, включая несколько точек одновременно. **«Выделить точки CJ»** выделяет все видимые незаблокированные точки; для старых точек добавляет видимые маркеры. При включённом автопересчёте после завершения перемещения обновляются результаты перемещённых точек. Undo/Redo возвращают положение и результат. Во время движения мыши расчёт не запускается. **«Пересчитать точки CJ»** обновляет выделенные точки, а без выделения — все видимые незаблокированные точки. Их предыдущие результаты заменяются. После изменения здания пересчёт нужно запустить кнопкой. Работа ведётся вне редактирования групп. Копии точек имеют отдельные результаты. Старые результаты без сохранённых точек автоматически не преобразуются.

Видимые номера убраны из подписей; внутренние номера сохранены. Предыдущие результаты временно скрываются для raycast, затем видимость восстанавливается. Вычисления пакетного расчёта выполняются порциями, есть прогресс и отмена. Отмена расчёта оставляет сохранённые точки для следующего запуска.

Режим **«Инсоляция — точка по окну»** предлагает положение точки по геометрии проёма и выступов. [Порядок работы и ограничения](WINDOW_POINTS.md).

Компоненты **«Вставить окно CJ»** и **«Рассчитать окна CJ»** позволяют разместить одинаковые окна с заранее заданными точками и рассчитать их одним пакетом. [Параметры и использование](WINDOW_COMPONENTS.md).

## Разработка

- `src/cj.rb` — расчёт, отображение и выбор точек.
- `src/window_placement.rb` — предложение точек по окнам.
- `dev/session.rb` — перезагрузка и проверки в SketchUp.
- `dev/window_examples.json` — геометрические примеры пользователя для регрессий.
- `reference/` — исторические копии; не используются рабочим расширением.

[Отдельный мост CJ Bridge, MCP и проверки](tooling/README.md). Мост имеет собственный загрузчик и панель, в RBZ инсоляции не входит. [Работа по примерам](tooling/EXAMPLES.md).

В Ruby Console загрузить `dev/session.rb` через `Kernel.load`, затем вызвать `CJDevelopment.reload` и `CJDevelopment.check`. Геометрические проверки выполняются через MCP `sketchup_run_geometry_tests` на свободной тестовой модели с откатом. Они проверяют программное поведение, а не нормативную достоверность выбранных направлений.
