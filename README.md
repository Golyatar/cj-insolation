# CJ — инсоляция в SketchUp

Ветка C++ движка: `codex/cpp-insolation-engine`. Расчёт использует исходные 510 направлений: одна выборка соответствует одной минуте. Методика пользователя: 90 минут непрерывно либо 120 минут прерывисто с сегментом не менее 60 минут.

## Работа в SketchUp

1. В **«Настройки CJ»** задайте размеры окна, вид результата (**Линии / Поверхность / Итоги**), радиус маркера и способ расчёта.
2. **«Инсоляция — выбрать точки»**: самостоятельно расставьте точки кликами. Enter сохраняет их и запускает расчёт; Backspace убирает последнюю; Esc отменяет выбор.
3. Точки сохраняются отдельными группами в SKP. Выделяйте их рамкой или с Shift и перемещайте обычным Move (M). **Автоматических и динамических расчётов нет.**
4. **«Пересчитать точки CJ»** пересчитывает выделенные точки; без выделения — все видимые незаблокированные точки. Предыдущие результаты заменяются. **«Выделить точки CJ»** выделяет все доступные точки.
5. **«Вставить окно CJ»** размещает окна с размерами из настроек. **«Рассчитать окна CJ»** рассчитывает их встроенные точки. [Окна и параметры](WINDOW_COMPONENTS.md).

Поиск точки выбором окна, стены и поверхностей удалён. Видимые номера скрыты. Зелёный цвет означает свободное направление, красный — затенение. Точки и результаты сохраняются в SKP. В окне прогресса доступна отмена; изменения можно отменить через Undo.

## C++ расчётчик

Плагин передаёт снимок видимой геометрии отдельному локальному `cj_engine.exe`. Движок строит BVH и параллельно ищет ближайшие пересечения лучей с треугольниками. Он не обращается к SketchUp API и не требует Codex, Python или моста на компьютере пользователя. EXE включается в RBZ при сборке.

Обычные отверстия в гранях, вложенные группы, повороты, отражения и масштабирование проверены сравнением со SketchUp. Для приклеенных компонентов с автоматическим прорезанием проёма, активных сечений и изображений используется штатный расчёт SketchUp. При отсутствии EXE также используется SketchUp. Выбор **«SketchUp (совместимость)»** всегда включает исходный расчёт.

На синтетической сцене из 1000 блоков проверено 16 448 лучей без расхождений: SketchUp — 1139 мс, C++ с экспортом геометрии — 102 мс. Это один тест, без построения результатов; скорость на рабочих моделях нужно измерять отдельно.
