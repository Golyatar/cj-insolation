# CJ — инсоляция в SketchUp

Расчёт нескольких точек по фиксированному набору из 510 направлений. Одна выборка соответствует одной минуте. Пользовательская методика: 90 минут непрерывно либо 120 минут прерывисто с сегментом не менее 60 минут; пороги проверяются тестами.

## Использование

Установить `dist/cj-insolation-0.2.0.rbz` через Extension Manager в SketchUp 2022+. Codex, MCP и Python для расчёта не нужны. [Инструкция](INSTALL.md).

Команда CJ предлагает три вида результата: **Линии**, **Поверхность**, **Итоги**. После выбора режима можно сразу выбирать точки. Enter запускает расчёт, Backspace убирает последнюю точку, Esc отменяет выбор. Лучи зелёные на свободных направлениях и красные на затенённых. Поверхности полупрозрачные; подписи минут ведут отдельный накопленный счёт солнца и тени с единицы.

Номер точки сохраняется в модели, названии подгруппы и подписи; следующие расчёты продолжают нумерацию. Предыдущие результаты временно скрываются для raycast, затем видимость восстанавливается. Вычисления выполняются порциями, есть прогресс и отмена. Результаты сохраняются внутри модели.

Режим **«Инсоляция — точка по окну»** предлагает положение точки по геометрии проёма и выступов. [Порядок работы и ограничения](WINDOW_POINTS.md).

Компоненты **«Вставить окно CJ»** и **«Рассчитать окна CJ»** позволяют разместить одинаковые окна с заранее заданными точками и рассчитать их одним пакетом. [Параметры и использование](WINDOW_COMPONENTS.md).

## Разработка

- `src/cj.rb` — расчёт, отображение и выбор точек.
- `src/window_placement.rb` — предложение точек по окнам.
- `dev/session.rb` — перезагрузка и проверки в SketchUp.
- `dev/window_examples.json` — геометрические примеры пользователя для регрессий.
- `reference/` — исторические копии; не используются рабочим расширением.

[Мост, MCP и проверки](tooling/README.md). [Работа по примерам](tooling/EXAMPLES.md).

В Ruby Console загрузить `dev/session.rb` через `Kernel.load`, затем вызвать `CJDevelopment.reload` и `CJDevelopment.check`. Геометрические проверки выполняются через MCP `sketchup_run_geometry_tests` на свободной тестовой модели с откатом. Они проверяют программное поведение, а не нормативную достоверность выбранных направлений.
