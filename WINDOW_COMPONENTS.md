# Окна CJ с готовыми расчётными точками

На панели CJ есть две команды:

1. **«Вставить окно CJ»**: задайте размеры и размещайте копии на наружных вертикальных гранях. Esc завершает размещение. Базовая плоскость компонента — XY, локальная Y направлена вверх, локальная Z наружу. Начало координат — нижний левый угол проёма.
2. **«Рассчитать окна CJ»**: найдёт все видимые вертикальные экземпляры, включая окна во вложенных группах, предложит режим отображения и запустит пакетный расчёт. Повторное использование одной компонентной дефиниции не объединяет экземпляры: каждое окно получает свою точку.

Тестовый габарит — **1300 × 1400 мм** (ширина × высота). Это выбранный типовой вариант из каталога: https://oknardia.ru/catalog/standard_opening/. Это не универсальный размер для всех домов и не нормативное требование.

Остальные исходные значения — параметры нашего прототипа, а не размеры из каталога:

| Параметр | По умолчанию |
|---|---:|
| Толщина стены / откосов | 300 мм |
| Посадка внутренней линии окна от наружной стены | 150 мм |
| Глубина рамы | 70 мм |
| Ширина рамы | 60 мм |

В компоненте есть рама, центральная стойка, откосы и координаты расчётной точки в атрибутах; отдельный маркер не создаётся. Световые отверстия не закрыты геометрией стекла: прозрачная грань SketchUp тоже может перехватить raycast. Локальная точка вычисляется пересечением боковых границ в плане и вертикали с плоскостью от верхней наружной линии проёма к нижней внутренней линии окна. Координаты сохраняются в атрибутах определения компонента `CJ_Window/point_mm`, размеры — `parameters_mm`.

Перенос, поворот вокруг вертикали, отражение и масштабирование экземпляров учитываются преобразованием локальной точки в мировые координаты. Ручное изменение геометрии внутри определения без изменения параметров не пересчитывает точку; для другого окна создайте новый вариант через команду вставки. Наклонённые и перевёрнутые окна пропускаются.

**Соседние козырьки и боковые выступы участвуют в затенении лучей, но не перемещают заранее заданную точку.** Для точки, зависящей от таких выступов, используйте режим «Точка по окну» либо создавайте отдельный параметрический тип окна после уточнения правила.

Нативное приклеивание режет грань, на которую вставлен компонент. Сквозной проём через обе поверхности толстой стены автоматически не создаётся: внутреннюю грань нужно открыть отдельно или разместить окно в уже готовом проёме. В группе стены сначала создайте проём/разместите экземпляр в её контексте обычными инструментами SketchUp; команда вставки CJ начинается из корня модели. Обход окон внутри вложенных групп поддерживается.

Проверки в SketchUp: наличие координат в метаданных без видимого маркера, вложенные копии с поворотом, исключение скрытых и наклонённых окон, raycast через приклеенное отверстие, откат временного стенда. Размещение мышью требует проверки пользователем.
