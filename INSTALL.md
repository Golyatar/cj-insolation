# Установка и использование

1. SketchUp 2022+ на Windows x64: Extensions → Extension Manager → Install Extension → выбрать RBZ.
2. После установки перезапустить SketchUp. Открыть панель **CJ Инсоляция · C++**.
3. **«Настройки CJ»**: размеры окна, вид результата, радиус маркера и способ расчёта. Сохранить.
4. **«Инсоляция — выбрать точки»**: клики добавляют точки; Enter сохраняет и рассчитывает их; Backspace убирает последнюю; Esc отменяет выбор.
5. Для изменения расположения выделить точки и использовать обычный Move (M). Затем нажать **«Пересчитать точки CJ»**. Без выделения пересчитываются все видимые незаблокированные точки.
6. **«Вставить окно CJ»** размещает окна с заданными размерами; **«Рассчитать окна CJ»** рассчитывает их встроенные точки.

Автопересчёта и инструмента определения точки выбором поверхностей нет. Сохранённые точки и результаты находятся в SKP. Старые результаты без самостоятельных точек автоматически не преобразуются в точки.

В режиме C++ используется входящий в сборку локальный EXE; отдельная установка движка, Python или моста не нужна. Для неподдерживаемой геометрии (приклеенные прорезающие окна, включённые активные сечения) используется SketchUp. В настройках можно выбрать штатный расчёт явно.

Направления фиксированы для исходной задачи; дата, география и север автоматически не подбираются. Методика и число направлений при переходе на C++ не изменяются.
