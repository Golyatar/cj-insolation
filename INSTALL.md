# CJ — установка и использование

1. SketchUp 2022+: Extensions → Extension Manager → Install Extension.
2. Выбрать `cj-insolation-0.2.0.rbz`.
3. Открыть панель **CJ** и нажать **«Инсоляция — выбрать точки»**.
4. Выбрать **Линии**, **Поверхность** или **Итоги**.
5. Кликами добавить точки. Enter — расчёт, Backspace — убрать последнюю, Esc — отмена.

Результат — группа внутри модели, по одной подгруппе на точку. Номера и подписи сохраняются в SKP. Свободные направления зелёные, затенённые красные. Поверхность имеет 50% прозрачности с обеих сторон. Подписи минут начинаются с единицы и ведут отдельный накопленный счёт солнца и тени.

Для полуавтоматического размещения нажать **«Инсоляция — точка по окну»**: выбрать грань рамы и наружную стену, проверить подсветку, при необходимости уточнить выступы, добавить предложенную точку. [Полная инструкция](WINDOW_POINTS.md).

Один вектор соответствует одной минуте. Направления фиксированы для исходной задачи пользователя; север, дата и география автоматически не подбираются. Проверяемые пороги: 90 минут непрерывно либо 120 минут прерывисто с интервалом не менее 60 минут.

Предыдущие результаты исключаются из следующих расчётов. Плагин показывает прогресс; отмена удаляет частичный результат. Последний расчёт можно отменить через Undo.

Для обычного использования нужны только SketchUp и RBZ. Мост, MCP, Python и Codex предназначены для разработки.

## Оформление и обновления

Кнопка с ползунками «Оформление результатов»: радиус сфер в миллиметрах (по умолчанию 100; 0 отключает). Настройка действует на новые расчёты. У окон CJ вместо сферы появляется вертикальная плоскость. Зелёный цвет означает прохождение критериев, красный — непрохождение.

В панели тегов раскройте папку «Инсоляция»: зелёные лучи и сегменты, красные лучи и сегменты, сферы, плоскости окон и подписи выключаются независимо. Сама папка выключает всё. Уже построенные старой версией результаты не перестраиваются автоматически.

Кнопка с круговыми стрелками «Версия и обновления»: «Проверить», затем «Установить обновление», если вышла более новая версия. После установки сохраните модель и перезапустите SketchUp. При запуске проверка выполняется автоматически не чаще раза в день. Для старой версии 0.1.0 первый переход требует установки нового RBZ через Extension Manager.
