# CJ Инсоляция 0.1.0 — установка и работа

## Для коллег

Нужен настольный SketchUp 2022 или новее. Проверено на SketchUp 2022 для Windows.
SketchUp Web не поддерживается. Codex, Python, MCP и Git для работы плагина не нужны.

1. Возьмите `cj-insolation-0.1.0.rbz` из папки dist или релиза GitHub.
2. В SketchUp откройте Extensions → Extension Manager → Install Extension.
3. Выберите RBZ. Плагин появится как «CJ Инсоляция — Владивосток».
4. Запустите Extensions → CJ → «Инсоляция — выбрать точки» или кнопку CJ.
5. Выберите режим отображения, затем папку для CSV. Последняя папка запоминается.
6. Кликайте по расчётным точкам. Enter — расчёт, Backspace — убрать последнюю,
   Esc — отменить выбор. Номер точки сохраняется в модели и в CSV.

Если раньше вручную устанавливались `cj.rb` и `cj_loader.rb`, перед установкой
сохраните их копии и уберите старую версию из папки Plugins при закрытом SketchUp.
Одновременная загрузка старого CJ и нового расширения может переопределить методы.

Расширение не подписано и не опубликовано в Extension Warehouse. Если политика
вашей организации блокирует неподписанные расширения, согласуйте установку с IT.

## Расчёт и отображение

Векторы зафиксированы для используемой автором методики Владивостока. Шаг —
один вектор на минуту. Перед использованием проверьте ориентацию модели и
соответствие исходного набора вашей расчётной задаче. Плагин не определяет север
автоматически и не проверяет нормативную применимость исходных векторов.

Правила прохождения заданы автором: >=90 минут непрерывно ИЛИ >=120 минут
прерывисто, включая сегмент >=60 минут. В CSV есть решение и оба признака.

Конусы — объёмная геометрия. Линии — быстрые красные/зелёные рёбра.
Поверхность — полупрозрачный красно-зелёный веер с подписями минут.
Итоги — только подписи. Результаты прошлых запусков исключаются из пересечений.

Условия проверяются центральными лучами. Заполнение между соседними лучами —
визуальная интерполяция. Нумерация минут солнца и тени ведётся отдельно от 1.

## CSV

После каждого расчёта создаётся отдельный файл в выбранной папке. Имя содержит
дату и уникальный ID. Excel: UTF-8 с BOM, разделитель `;`, десятичная запятая.
Номер строки соответствует постоянному номеру точки в модели.
Отмена выбора папки отменяет запуск до создания результата.

## Обновление

Установите новую версию RBZ через Extension Manager и перезапустите SketchUp.
Модель, отчёты и номера точек остаются отдельными от файлов расширения.

## Разработка

Из корня исходников: `python tooling/build_release.py`.
Инструментарий Codex/MCP — только для разработчика, в устанавливаемый RBZ не входит.
