# Выпуски CJ для коллег

Git хранит историю исходников. GitHub Releases хранит готовые выпуски RBZ. Это разные задачи: каждый коммит не обязан становиться выпуском.

## Выпуск

1. Поднять номер в единственном файле `src/version.rb`.
2. Записать изменения в CHANGELOG.md и выполнить подходящие проверки в SketchUp.
3. Запустить `python tooling/build_release.py`: он берёт версию из того же файла, создаёт RBZ, исходный архив и SHA256SUMS. EXE берётся только из `native/stable/` с проверкой SHA256 по манифесту. Экспериментальные сборки из `native/build/experimental/` в RBZ не попадают. Отсутствие рабочей копии останавливает упаковку; пересборка не заменяет её автоматически.
4. Закоммитить и отправить согласованные изменения минимальным Git-процессом. Затем создать тег `v0.2.0` на этом коммите и GitHub Release, прикрепив соответствующий RBZ, архив исходников и контрольную сумму.
5. Не менять файлы уже опубликованного выпуска. Исправление публиковать с новым номером.

Пример нумерации: `0.2.1` — исправление, `0.3.0` — новая функциональность, `1.0.0` — согласованный стабильный выпуск. Формат атрибутов модели версионируется отдельно; изменение номера плагина само по себе не меняет старые окна и точки.

## Обновление у коллеги

Публичный репозиторий: вход в GitHub не требуется. В плагине кнопка «Версия и обновления» проверяет последний стабильный GitHub Release. При запуске выполняется фоновая проверка не чаще раза в день; новая версия открывает уведомление с кнопкой установки.

Обязательные вложения каждого выпуска: `cj-insolation-X.Y.Z.rbz` и `SHA256SUMS.txt` из одной сборки. Тег: `vX.Y.Z`. Без этих файлов обновление не предлагается. RBZ скачивается по нажатию, сверяется SHA-256 и устанавливается стандартным установщиком SketchUp. Подтвердите его запрос, затем сохраните работу и перезапустите SketchUp.

Для первого перехода со старой версии без обновлятора установите новый RBZ вручную через Extension Manager. Дальше обновляйте из плагина.

Локальная сборка не означает публикацию: GitHub Release и тег создаются при отдельном выпуске.
