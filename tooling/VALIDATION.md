# Проверка инструментария — 14 октября 2026

Среда: SketchUp 2022 22.0.316, Ruby 2.7.2, Windows, часовой пояс Asia/Vladivostok.

После однократной загрузки моста через Ruby Console команды выполнялись
PowerShell-клиентом через JSON-файлы, без управления экраном.

| Проверка | Результат |
|---|---|
| `status` | Ответ живого процесса SketchUp получен |
| `reload` | Рабочая копия плагина загружена |
| `check` | 7 из 7 проверок прошли, загружены 510 векторов |
| `geometry_test` | 5 из 5 проверок прошли |
| `raycast` | Ответ без пересечения для луча вверх из точки на высоте 1000 м |
| Ошибочный `raycast` с нулевым направлением | Структурированная ошибка ArgumentError; после неё мост продолжил выполнять проверки |

Геометрические проверки подтвердили:

1. Луч находит стену внутри вложенной группы.
2. Видимая тестовая преграда перехватывает луч перед стеной.
3. Скрытая тестовая преграда исключается при `raytest(..., true)`.
4. Скрытая тестовая преграда снова учитывается при `raytest(..., false)`.
5. После отката операции тестовая группа недействительна, количество объектов
   корня модели совпадает с количеством до теста.

Найдена и исправлена проблема клиента: PowerShell 7 автоматически преобразует
дату JSON в DateTime; повторный Parse терял UTC и ошибочно определял heartbeat
как устаревший. Клиент теперь преобразует значение напрямую в DateTimeOffset.

Эти результаты подтверждают работоспособность моста и поведение raytest.
Пакетный выбор точек и исправление влияния старых результатов ещё не реализованы.
