# Инструментарий разработки SketchUp

Это главная страница для обсуждения инструментов. Начать чтение можно здесь;
исходники инструментов рядом, результаты тестов — в папке `reports` проекта.

## Как устроена связь

```text
Codex → PowerShell-клиент → JSON-запрос в папке проекта
                                   ↓
                  Ruby-мост в запущенном SketchUp
                                   ↓
                         SketchUp Ruby API
                                   ↓
Codex ← JSON-ответ с результатом или ошибкой
```

Мост и MCP — разные вещи. Мост выполняет работу внутри SketchUp.
MCP — стандарт подключения инструментов к Codex. MCP-сервер отправляет те же
запросы мосту. Такой сервер уже создан и зарегистрирован в конфигурации Codex:
[описание и подключение MCP](mcp/README.md). PowerShell-клиент остаётся доступен
для диагностики независимо от MCP.

Возможно, под «MOST» имелся в виду именно мост. Отдельный продукт с этим названием
мы пока не выбирали.

Никаких ключей OpenAI API, новых библиотек, открытых сетевых портов или облачного
сервиса для текущего варианта не нужно. Он использует Ruby установленного SketchUp
и PowerShell на компьютере.

## Запуск

Мост уже загружен в текущий сеанс. После перезапуска SketchUp открыть
Extensions → Developer → Ruby Console и один раз выполнить:

```ruby
Kernel.load('C:/Users/Golyatin.av/Documents/ChatGPT/Skethcup инсоляция/tooling/sketchup_bridge.rb')
```

Обычный `load` перехватывается установленным RhinoInsideSU, поэтому используется
явный `Kernel.load`. Автозагрузка через Plugins пока не установлена.

Дальше команды выполняются из PowerShell в корне проекта; пользователю запускать
их вручную необязательно — это делает Codex:

```powershell
& .\tooling\request.ps1 -Command status
& .\tooling\request.ps1 -Command reload
& .\tooling\request.ps1 -Command check
& .\tooling\request.ps1 -Command geometry_test
& .\tooling\request.ps1 -Command raycast -ArgsJson '{"origin_mm":[0,0,1000000],"direction":[0,0,1]}'
```

Остановить мост:

```powershell
& .\tooling\request.ps1 -Command stop
```

Либо в Ruby Console: `CJBridge.stop`. Повторная загрузка файла запускает мост
с новым идентификатором сеанса. Старые запросы ему не подходят.

## Команды и их воздействие

| Команда | Назначение | Воздействие |
|---|---|---|
| `status` | Версии, состояние моста, количество объектов корня модели | Читает состояние |
| `reload` | Загрузка рабочей версии плагина | Переопределяет код текущего сеанса; файл Plugins не меняет |
| `check` | 7 базовых проверок | Пишет отчёт; при первом обращении может загрузить рабочий плагин |
| `raycast` | Проверка заданного луча | Читает модель; координаты входа/выхода в мм; скрытая геометрия исключается |
| `geometry_test` | 5 проверок на временной стене и конусе | Создаёт геометрию внутри операции, затем откатывает её |
| `stop` | Остановить обработку запросов | Останавливает таймер моста |

Геометрические тесты запускать на тестовой модели, когда другой инструмент
не выполняет изменения и пользователь не редактирует модель одновременно.
При открытой группе или компоненте тест отказывается запускаться. Тесты не
сохраняют модель и не меняют положение камеры. Они подтверждают поведение API,
а не исправление алгоритма плагина или соответствие СП.

## Где смотреть результаты

- `reports/session_check.json` — последний результат базовых проверок.
- `reports/geometry_check.json` — последний результат геометрических проверок.
- `tooling/runtime/session.json` — состояние подключения и heartbeat.
- `tooling/runtime/<id>.response.json` — ответ каждой отдельной команды.
- `tooling/runtime/<id>.handled.json` — обработанный запрос, оставленный для диагностики.
- [VALIDATION.md](VALIDATION.md) — краткий журнал проверки инструментария.
- [ROADMAP.md](ROADMAP.md) — что добавлять дальше и зачем.

В ответах есть `ok` для успеха выполнения команды и `passed` для успеха набора
проверок. Клиент сообщает ошибку в обоих случаях неуспеха. Отчёты и очередь
исключены из Git; их можно архивировать отдельно при воспроизведении ошибки.

## Ограничения первой версии

SketchUp должен быть запущен, мост должен быть загружен, а его цикл UI — свободен
для обработки таймера. Активное модальное окно или длительный расчёт может
задержать ответ. Таймаут — 30 секунд, на стороне клиента максимум 60 секунд.
Истечение таймаута не прерывает уже начавшийся расчёт: сначала нужно проверить
его ответ, чтобы не запустить действие второй раз.

В этой папке обслуживается один процесс SketchUp. Есть идентификатор сеанса,
heartbeat, ограничение размера запроса и срока действия. Это средство локальной
разработки; доступ к папке проекта позволяет отправлять команды. Произвольного
`eval`, исполнения shell-команд или загрузки пути из запроса нет. Однако `reload`
исполняет рабочие исходники проекта; это доверенный код разработчика.

API-команды не требуют переключения окон. Снимки экрана всё ещё полезны при
проверке поведения мыши, диалогов, расположения подписей и внешнего вида лучей.
