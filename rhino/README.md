# CJ Инсоляция для Rhino — прототип 0.1

Первый адаптер к сохранённому рабочему C++ движку. Проверен в Rhino 7.37 Windows / IronPython 2.7. Rhino 8 ещё не проверен. SketchUp-плагин и его выпуск 0.3.0 не изменены.

## Запуск из рабочего проекта

В Rhino выполните `_RunPythonScript` и выберите `rhino/launch.py`. Откроется отдельная панель. Для работы панели MCP не требуется; путь проекта можно добавить в кнопку Rhino. Автозагрузка и установка в системные папки не выполняются.

1. «Расставить точки»: кликами укажите точки, Enter завершает ввод. Они сохраняются в 3DM как обычные точки с атрибутом CJ, на слое «Инсоляция::Расчётные точки».
2. Выделяйте несколько точек и перемещайте обычным Move. Динамических расчётов нет.
3. Выберите «Итоги и сферы» или «Линии, итоги и сферы», радиус сфер и допуск сетки поверхностей (по умолчанию 1 мм).
4. «Пересчитать точки»: пересчёт выбранных сохранённых точек; если они не выбраны — всех видимых незаблокированных точек CJ.
5. Результаты — в слоях «Инсоляция::Проходят» и «Инсоляция::Не проходят», с отдельными лучами, сферами и подписями. Пересчёт заменяет результаты только затронутых точек. Непосчитанные исходные точки остаются отдельно.

Используются те же 510 направлений и критерии, что в SketchUp: один отсчёт равен минуте; 90 минут непрерывно либо 120 минут суммарно при двух и более интервалах с максимальным не менее 60 минут. Местоположение, дата и север заново не вычисляются: ориентация осей должна соответствовать исходной схеме SketchUp. Это перенос существующей методики, без новой нормативной модели.

## Геометрия и ограничения

- Сетки, Brep/NURBS, поверхности и экструзии; вложенные блоки с преобразованиями. Скрытые объекты и родительские слои исключаются. Видимая заблокированная геометрия учитывается.
- Единицы Rhino переводятся в дюймы протокола v1. Перед экспортом координаты смещаются относительно первой точки, чтобы не терять точность на больших координатах.
- Сетки поверхностей создаются только в памяти. Исходные объекты, слои застройки и файл на диске не переписываются.
- Экспорт идёт порциями на UI-таймере. Само построение сетки одной Brep выполняется синхронно: сложная поверхность ещё может задержать интерфейс и отмену. Шкала — доля обработанных объектов, не прогноз общего времени. Во время C++ расчёта — индикатор ожидания.
- Геометрия проверяется перед выводом. Если видимая сцена или исходные точки изменились за время расчёта, результаты не заменяются; нужен явный повторный запуск.
- Точность пересечений поверхностей зависит от сетки. Допуск — настройка аппроксимации, а не доказанная граница погрешности всего расчёта.
- SubD, clipping planes и другие неподдерживаемые видимые геометрические типы останавливают расчёт с сообщением. Плоскости отсечения пока не применяются. Представления Grasshopper не экспортируются до Bake.
- Пока нет расстановки окон, режима поверхностей результатов, установщика RHP/Yak и автоматических обновлений Rhino.

Исполняемый файл берётся из `rhino/bin/cj_engine.exe`, если он размещён при отдельной упаковке, иначе из `native/stable/cj_engine.exe`. Перед запуском проверяется закреплённый SHA256. Экспериментальные EXE не используются и не собираются. Настройки антивируса не меняются.

## Проверки

`python dev/rhino_protocol_checks.py` — совпадение направлений с Ruby, границы критериев, единицы, повреждённые ответы и проверка EXE; без запуска движка.

В Rhino добавьте каталоги `rhino` и `dev` в `sys.path`, затем `import rhino_checks; rhino_checks.run_async()`. Проверки создают отдельные headless-документы и освобождают их: 3060 лучей против Rhino MeshRay в мм/м/дюймах, вложенные отражённые блоки, скрытые объекты/родительские слои, ручные точки, замена результатов, отмена и Brep. Отчёт: `reports/rhino_check.json`.

`rhino_model_check.start()` — отдельный тест для текущей модели с одной видимой сеткой, с виртуальными точками и без вывода объектов. На проверенной плоской сетке: 9801 треугольник, 1530 лучей, 0 расхождений, около 0,62 с без построения графики. Это не замер на объёмной застройке. Отчёт: `reports/rhino_model_check.json`.

Документация McNeel: [сетки из Brep](https://developer.rhino3d.com/api/rhinocommon/rhino.geometry.mesh), [отдельные документы для тестов](https://developer.rhino3d.com/api/rhinocommon/rhino.rhinodoc/createheadless).
